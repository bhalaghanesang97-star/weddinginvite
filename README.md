# South Indian Wedding Invitation

Static wedding invitation replica with temple artwork, event cards, gallery, background music, countdown, and a local demo RSVP form.

GitHub Pages deployment: select **Settings → Pages → Deploy from a branch → main → / (root)**.

No build step or dependencies are required. Open `index.html` locally or serve this folder with any static web server.

The names, dates, family details, location, and phone number are sample content from the reference. RSVP submissions are saved only in the visitor's browser and are not sent to the couple.

Reference: https://craftyart.cloud/view/crt25
